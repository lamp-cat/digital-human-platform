# 虚拟直播间

首页把人物装扮、虚拟直播间和真人视频复现拆为三个一级工作区。`/motion/:avatarId`
只负责 VTuber 风格的虚拟直播间；`/video/:avatarId` 单独负责真人视频导入、复现和导出。
房间模型、人物模型、摄像头画面和真人源视频均在浏览器本地处理。

## 使用方法

1. 在首页选择“虚拟直播间”，再选择本次直播使用的数字人。
2. 在“场景与机位”标签恢复、隐藏或导入房间，并调整人物站位。
3. 正面、近景、45°、侧面和全景是快捷构图起点，不是固定限制。可直接编辑相机
   X/Y/Z、注视点 X/Y/Z 与 20°–70° FOV；也可在画面中左键旋转、右键平移、
   滚轮缩放，再点“读取左侧当前视角”同步数值。
4. 满意后保存最多 4 个自定义机位，以便直播过程中快速切换。
5. 切到“动作驱动”播放待机、挥手、走路、坐下、站起、捧腹大笑、欢呼和鞠躬，
   或启动本地摄像头驱动。
6. 需要细节控制时再进入“面部与手部”，避免场景、动作、面部和手部设置同时堆在页面中。

真人视频复现从首页的独立入口进入 `/video/:avatarId`，该页面只显示视频导入、
精准/流畅识别、预览与 MP4/WebM 导出，不再混入直播间的房间、摄像头和手脸面板。

人物坐着或处于起坐过渡时不能直接启动摄像头驱动，需要先完成“站起”，以防实时骨架和坐姿末帧冲突。

## 房间导入

| 格式 | 支持情况 |
| --- | --- |
| GLB | 推荐；模型、材质和贴图可封装在单个文件中 |
| glTF | 支持嵌入资源的单文件；引用外部 `.bin` 或贴图时请改导出 GLB |
| FBX | 支持几何和文件内数据；外部贴图依赖不会自动收集 |
| OBJ | 支持几何；当前不额外读取 MTL/外部贴图 |

单个文件上限为 80 MB。导入后会自动把模型水平跨度归一到约 6 米并贴合地面；新模型只有在解析和网格边界检查成功后才会替换现有房间。房间字节不会上传到 API。

## 动作与骨架稳定性

- 所有预置动作使用同一套 `StandardRig` 定义。
- 导入人物按完整父骨骼链计算世界旋转增量，再结合模型自身绑定姿态反解局部四元数，兼容肩部等辅助节点的初始旋转。
- 坐下和站起共享严格互逆的关键帧，坐姿/站姿使用单次播放和末帧保持。
- 动作切换采用 0.35 秒交叉淡化；起坐期间锁定冲突操作，减少跳帧和抽动。
- 自动化测试会验证坐下末帧与站起首帧逐轨一致，并验证带非零胸部、肩部绑定旋转的导入骨架方向。
- 全身实时/视频驱动会估算髋部到支撑脚的垂直高度，用 Hips 位移补偿腿部弯曲，让数字人可以真正蹲下；站姿死区、One Euro 和最大位移速度用于抑制上下抽动。上半身模式不参与髋关节和根位移。
- 转体不再只看髋线或脊柱竖线：肩线、髋线和髋肩竖轴共同恢复三维身体朝向。全身模式让 Hips、Spine、Chest、UpperChest 共同转向，上半身模式只让 Spine/Chest 跟随，仍不控制髋关节。Neck 和 Head 以肩胸绝对朝向为基准再叠加头部局部动作，因此背身时头会随身体转，鼻点短时丢失也不会固定在世界正面。
- 水平朝向与俯仰/侧弯分别限幅：支持接近 180° 的侧身、背身及肩髋分离扭腰，同时限制深度噪声造成的躯干翻倒。

## 真人视频复现与导出

- 支持 MP4、WebM、MOV、M4V，单文件上限 500 MB / 15 分钟。
- 首次运行会跨时间轴寻找清晰全身片段，再围绕最佳片段标定人体比例与头部中性基准，因此允许视频带片头或空镜。
- 身体使用 Pose Heavy/Full 模型，手部使用双手 21 点模型；源画面不做镜像，左右按解剖学对应。
- 关键点使用视频媒体时间戳进入滤波和跟踪丢失回退，暂停、重播或导出时不会因墙钟时间产生突跳。
- 对低置信或短时缺失关键点，先按历史速度阻尼预测，再融合当前弱检测持续重锚，并用已学习的上/下臂和大小腿长度约束端点，减少遮挡、转身和快速动作引起的拉伸与抽搐。没有任何检测超过 1.2 秒后停止外推。
- 视频页把 MediaPipe 原始均值与推理后的有效置信度分开显示，并报告 ≥80% 有效帧覆盖、人物追踪覆盖及每帧推理点数。长期人物离场不计入有效姿态置信度，也不会被伪装成识别成功。
- 导出由浏览器捕获 Three.js 最终画布，默认使用 H.264/AAC-LC MP4，也可手动选择 VP9/VP8 WebM 兼容格式。运行前通过 `MediaRecorder.isTypeSupported()` 探测实际能力，下载扩展名取自最终 Blob MIME，不会把 WebM 伪装为 MP4。支持时合并原视频音轨，否则输出无声视频；所有源文件、关键点和输出 Blob 均停留在本机。

## 开源房间素材

默认房间选用 [Kenney Furniture Kit](https://kenney.nl/assets/furniture-kit) 2.0 的 11 件家具，许可证为 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。项目仅挑选了直播布景需要的小体积 GLB 文件，原始许可证保存在 `apps/web/public/rooms/kenney/LICENSE.txt`。

当前房间、站位和自定义机位属于直播编排会话状态，刷新页面后会恢复默认配置。
